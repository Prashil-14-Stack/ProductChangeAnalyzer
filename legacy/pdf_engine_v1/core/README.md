# ProductChangeAnalyzer – PDF Engine V1

## Status
Archived

## Objective
Build a generic PDF layout understanding engine for insurance product specifications.

## Achievements

- PyMuPDF Reader
- Raw Layout Extraction
- Logical Line Builder
- Layout Relationships
- Reading Order
- Table Detection (Prototype)
- Table Reconstruction (Prototype)

## Reason for Archiving

The project direction changed.

Instead of solving generic PDF layout understanding, Version 2 focuses on:

PDF → LLM → Structured JSON → Comparison → Report Generation

The V1 engine is retained for future reference and possible reuse.
